# Decision record: Why RELAY, not a generic Startup Operations Control Plane

**Target:** SolveAI Operations generalist (London on-site), as described in the vacancy supplied by the applicant. SolveAI's role spans joiner hardware and access, customer assurance requests, invoices and expenses, contracts/renewals, hiring, CRM preparation and executive events.

## Original idea evaluated

- A seven-module operations dashboard is role-relevant but overlaps substantially with the existing BACKBONE founder operations prototype, and broad modules risk looking functional while doing little beyond status labels.
- An autonomous 150-question AI security reviewer is tempting but invites unsupported claims. A convincing product would need verified source evidence, scoping, version freshness, approval authority, and disclosure governance before any answer can leave the system.

## Chosen product

**RELAY**: synthetic operations readiness workbench. Go narrow and deep on **joiner/leaver access lifecycle** and **enterprise customer assurance**, joined by a source freshness rule. Preserve a smaller but working operational register for the true generalist responsibilities.

## Success criteria

1. Access and assets cannot be declared ready merely by selecting a status.
2. Offboarding cannot close with unreconciled access or device return.
3. A questionnaire answer requires manually drafted text, compatible control/evidence, unexpired approved evidence and a typed reviewer record.
4. Any access change marks AC-01 source evidence stale and blocks previously approved questionnaire responses, until operators revise the source reference and re-approve both the evidence and answer.
5. Downloading a review never silently exports unapproved or stale claims.
6. Business follow-ups have owner/due/status with an audit entry and human closure note.
7. Desktop and mobile navigation, errors and core UI actions work on testable synthetic data.

## Explicit non-goals

Real external access provisioning, a compliance certification, an actual security-questionnaire auto-answering model, a real vendor contract signing flow, a full CRM, payroll/payables, immigration legal determinations, and enterprise security claims.

## What would kill this project

If business rules can be bypassed through the API; if UI buttons are dead or misleading; if stale evidence remains exportable; if the experience is only a static dashboard; if it falsely implies operating access to SolveAI; or if no reasonable walkthrough can show the operations role being carried out.
